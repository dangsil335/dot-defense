# 폰트 넣는 자리

받은 폰트 파일을 **이 폴더에 그대로** 넣으면 된다. 나머지는 내가 처리한다.

```
fonts/
  ├── (여기에 받은 파일을 넣는다)
  └── README.md
```

## 무엇을 받으면 되나

**형식은 아무거나 좋다** — `.ttf` `.otf` `.woff` `.woff2` 다 받는다.
`.ttf`/`.otf` 로 받아도 내가 `woff2` 로 변환한다 (fontTools + brotli 준비돼 있음).
보통 3~5배 작아진다.

**굵기는 2개면 충분하다.** 본문용 하나, 강조용 하나.
파일명에 `Regular` `Bold` `ExtraBold` 같은 게 들어 있으면 그대로 두면 된다 — 내가 알아서 읽는다.

## 레퍼런스(스텔라소라·블루아카이브) 느낌에 가까운 무료 한글 폰트

| 폰트 | 받는 곳 | 비고 |
|---|---|---|
| **나눔스퀘어라운드** | hangeul.naver.com/font/nanum | 둥근 고딕. 레퍼런스에 가장 가깝다 |
| **에스코어드림** | s-core.co.kr/company/font | 9단계 굵기, 깔끔 |
| **Gmarket Sans** | corp.gmarket.com/fonts | 굵고 모던 |
| **Pretendard** | github.com/orioncactus/pretendard | 라운드는 아니지만 아주 깔끔 |

⚠ **상업 이용 가능한지 확인할 것.** 위 넷은 모두 가능하지만, 다른 폰트를 받을 땐
라이선스에 "임베딩/웹폰트 허용"이 있는지 봐야 한다. 게임에 넣으면 웹폰트 배포에 해당한다.

## 내가 할 일 (파일 넣으면)

1. `.ttf`/`.otf` → `woff2` 변환
2. **서브셋** — 한글 전체는 굵기당 1.5MB 다. 실제 쓰는 글자만 남기면 300~600KB
3. `@font-face` 등록 + `font-display: swap`
4. `sw.js` 프리캐시에 추가 → **오프라인에서도 폰트가 유지된다**
   (지금은 Google Fonts CDN 이라 오프라인이면 시스템 폰트로 떨어진다)
5. 인게임 캔버스 폰트 교체 — `Rajdhani` 가 **93곳에 하드코딩**돼 있다

## ⚠ 폭이 넓어지는 문제

지금 인게임 HUD 는 `Rajdhani` 라는 **콘덴스드(좁은)** 폰트를 쓴다.
일반 폰트로 바꾸면 같은 글자가 **약 11% 넓어진다** (실측: 숫자 최대 +16%).

```
1234567890   Rajdhani 69.2px  →  Jua 80.6px   (+16%)
999,999      Rajdhani 47.0px  →  Jua 53.5px   (+14%)
WAVE 12      Rajdhani 47.8px  →  Jua 53.7px   (+12%)
```

좁은 칸에 들어가는 숫자(웨이브, 골드, 배율)가 넘칠 수 있다.
폰트를 바꾼 뒤 인게임 HUD 를 실측해서 넘치는 곳을 잡아야 한다.
