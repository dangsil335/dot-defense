## 핵심 메커니즘 — 졸음(drowse)

**"재우고 → 깨운다" 가 딜 사이클이다.** CC 만으로는 적을 못 죽이므로 수면이 딜로 전환되는 경로를 반드시 둔다.

- 적에게 `e._drowse` 가 쌓인다 (최대 5). 지속 `e._drowseT = state.t + 240`(4초).
- 5스택이 되면 **잠든다**:
  - 비보스 → `e.timeStopped = Math.max(e.timeStopped || 0, state.t + 90)`
  - **보스는 정지 금지** → `e.slowFrames = Math.max(e.slowFrames || 0, 135)` 으로 대체 (기존 갈라테아·레비나 관례)
- **잠든 적이 피해를 받으면 깨어나며 누적 졸음에 비례한 추가 피해.** 이것이 딜의 축.
- **즉사·처형 메커니즘은 넣지 않는다** (스미카가 처형 담당 · 사용자 지시).
- **적을 아군으로 바꾸지 않는다** (진영 전환 없음 · 사용자 지시). "잠꼬대" 로 대체 — 잠든 적이 주변 적을 때린다.

### 공용 헬퍼 (스미카 `_sumiMarks` 선례를 따른다)

`damageEnemy` 근처, `_sumiMarks` 옆에 둔다. **여러 능력이 공유하므로 반드시 헬퍼 한 곳으로 모을 것.**

```js
// 💤 졸음 스택 — 만료 시각을 넘겼으면 0으로 본다(스미카 표식과 동일 규약).
function _drowse(e) { return (e._drowseT > state.t) ? (e._drowse || 0) : 0; }
function _drowseCap() {
  const ov = state.abilityStatOverrides && state.abilityStatOverrides.lullaby;
  return (ov && ov.drowseCap) || 5;
}
// 졸음 부여 + 만개 시 수면. 부여 후 현재 스택을 반환.
function _addDrowse(e, n) { /* 만료됐으면 0부터 다시 쌓기, cap 클램프, 만개 시 수면 */ }
// 잠들어 있나?
function _isAsleep(e) { /* 비보스는 timeStopped, 보스는 별도 플래그로 판정 */ }
```

**⚠️ 새 능력은 전부 `stats` 를 갖고 `const S = _S(ab);` 로 읽는다** (v678 에서 확립된 규약). 상수를 `tick` 본문에 리터럴로 박지 말 것.

### `lullaby` (자장가) — t1
최근접 적 1체에게 피해 + 졸음 +1. 졸음이 쌓인 적일수록 피해 증가(스택당 가산).
`stats: { drowseCap: 5, drowseDur: 240, sleepDur: 90, bossSlowDur: 135, wakeBonus: 0.5 }`

### `pillowThrow` (베개 던지기) — t2 조합
잠든 적을 우선 노려 베개를 던진다. 착탄 시 **광역**으로 깨우며, 깨어나는 적마다 누적 졸음 × `wakeBonus` 추가 피해. 잠든 적이 없으면 최근접 적에게 던지고 졸음 +1.

### `dreamland` (꿈나라) — t3 상위조합
바닥에 졸음 지대를 설치. 지대 안의 적에게 주기적으로 졸음 +1 + 소량 피해. 지대 안에서 잠든 적은 지대가 유지되는 동안 계속 잠들어 있다(재수면).

### `daydream` (백일몽) — t4 궁극
전 맵 광역 수면 후 **일괄 각성** — 잠든 적 전원을 동시에 깨우며 각자 누적 졸음에 비례한 피해. 보스는 수면 대신 강슬로우, 각성 피해는 받되 **40% 감쇠**(기존 `omniSolvent` 관례).

### `countingSheep` (양 세기) — 4★
양이 아레나를 굴러다니며 지나간 적에게 졸음 +1. 양은 일정 수 유지, 수명 있음.

### `somnambulism` (몽유) — 8★
잠든 적이 정지 대신 **비틀거리며 이동**하고, 주변 적과 부딪히면 양쪽에 피해. **진영은 바뀌지 않는다**(아군화 아님). 보스는 대상 제외.
