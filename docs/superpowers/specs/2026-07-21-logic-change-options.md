## A. 판정의 부재 — "빈 자리에 판정을 새로 만든다" (9건)

### sunspot (솔라) — 2차 고리 판정
- **현재 코드**: `index.html:14152-14166`. tick 은 중심 `CX, CY` 고정 단일 원판 판정 하나뿐. `radius = 90 + lv*15` 안의 적에게 `damageEnemy` 1회. 2차 판정 코드 없음. **stats 없음**(모든 값이 레벨식).
- **필요한 변경**: 2차 고리 판정을 **추가 패스로 신설**. 지연 발동(약 20프레임 뒤) 큐가 필요해 `ab` 에 대기열 상태가 새로 생긴다.
- **난이도**: 중간
- **위험**: 지연 큐가 능력 제거/교체 시점을 넘겨 살아남지 않도록 `init` 에서 비워야 한다.

### marionette (라라) — 실 선분 판정
- **현재 코드**: `index.html:16703-16721`. 인형–표적을 잇는 '실'은 `draw` 에서만 그려지고 tick 에 선분 판정이 **전혀 없다**. 피해는 `state.bullets` 투사체로만 들어간다.
- **필요한 변경**: 사격 순간 **선분–원 판정 루프 신설**(폭 약 12px). 현재 코드에 선분 판정 함수 호출 자체가 없다.
- **난이도**: 중간
- **위험**: 인형 수 × 적 수 루프가 새로 생긴다. 인형은 최대 5기 수준이라 감당 가능하나 상한 확인 필요.

### refractionField (블랑슈) — 광선 관통 판정
- **현재 코드**: `index.html:17063-17080`. 광선은 `ab.zaps` 에 좌표만 쌓여 `draw` 전용이고, 피해는 `damageEnemy(tgt, dmg)` 로 **종점 단일 대상**에만 들어간다.
- **필요한 변경**: **선분 관통 판정으로 교체**. 단일 호출을 CX,CY→표적 선분 위 적 전체 루프로 대체.
- **난이도**: 중간
- **위험**: 같은 능력의 표적 선정(§C)과 함께 바꾸면 피해량이 이중으로 뛴다. 두 옵션이 동시에 붙는 조합을 밸런스에서 따로 봐야 한다.

### beastForm (카이라) — 전환 순간 판정
- **현재 코드**: `index.html:17238-17250`. `ab.switchFx = 22` 는 `draw` 전용 연출 타이머이고, 전환 시점(`ab.timer >= S.switchInterval`)에 피해 판정이 **없다**.
- **필요한 변경**: 전환 시점에 **광역/투사체 발동 블록 신설**. 방향(인간→야수 / 야수→인간)별 분기가 필요.
- **난이도**: 낮음
- **위험**: 없음. 전환 지점이 단일 `if` 라 삽입 지점이 명확하다.

### sakuraSlash (사쿠라) — 꽃잎 판정
- **현재 코드**: `index.html:14662-14700`. 꽃잎 루프(`ab.petals`)에 `damageEnemy` 호출이 **아예 없다**. 순수 이펙트.
- **필요한 변경**: 꽃잎 객체에 `hit` Set 추가 + **꽃잎×적 판정 루프 신설**.
- **난이도**: 높음
- **위험**: 꽃잎이 상시 20~30개 체류해 `O(꽃잎×적)` 비용을 새로 지불한다. **성능 재측정 필수.** petalStorm 꽃잎과 시각적으로 구분되지 않으면 플레이어가 어느 쪽이 때리는지 알 수 없다.

### lunarRain (루나) — 크레이터 지속장 승격
- **현재 코드**: `index.html:16375-16410`. `ab.craters.push({..., life: S.craterLife})` 는 `life 16` 짜리 VFX. 크레이터에 판정 없음.
- **필요한 변경**: 크레이터를 **실효 지속장으로 승격**.
- **난이도**: 높음
- **위험**: ⚠️ 장이 겹칠 때 곱연산되지 않도록 `e._lunarZoneT` 같은 **적 1체당 개인 쿨** 필드가 반드시 함께 필요. 없이 풀면 5발이 겹친 지점에서 피해가 5배가 된다.

### thunderfall (레비나) — 착탄점 연결 아크
- **현재 코드**: `index.html:17731-17770`. 착탄점(`ab.shells`)끼리 **아무 관계가 없다**(완전 독립).
- **필요한 변경**: 착탄 순서를 기억하고 **선분–원 판정을 신설**해 i↔i+1 아크를 만든다.
- **난이도**: 중간
- **위험**: 현재 코드에 선분 판정이 없어 marionette 과 같은 헬퍼가 필요. 둘을 함께 만들면 중복을 줄일 수 있다.

### wildDeal (카르디스타) — 슈트별 효과 분기
- **현재 코드**: `index.html:17587-17620`. `col: SUITS[(Math.random()*3)|0]` 로 **색 문자열만** 저장되고 효과 분기가 0건. 모든 카드가 동일 피해.
- **필요한 변경**: 카드 객체에 `suit` **인덱스**를 심고 `cardThrow` 의 3분기 효과 블록(화상/둔화/치명+골드)을 이식.
- **난이도**: 낮음
- **위험**: 색 문자열만으로는 분기 불가하므로 객체 스키마가 바뀐다. `draw` 가 `col` 을 읽고 있어 함께 손봐야 한다.

### celestialEcho (아리아) — 지연 재타격
- **현재 코드**: `index.html:15995-16010`. 단일 전체타격 1회. 반복/지연 구조 없음. **stats 없음**(dmg·쿨다운 모두 레벨식).
- **필요한 변경**: **지연 재타격 큐 신설**(약 18f 간격 3연타) + 2·3타에 "즉사·처형 판정 미발동" 플래그.
- **난이도**: 중간
- **위험**: 전체 적 대상 능력이라 3연타면 피해가 3배. 트리나의 `_phantomDmg` 게이트 방식을 재사용해 판정 폭주를 막아야 한다.

## B. 소멸·수명 규칙 — "언제 사라지는가" (7건)

### torpedo (마린) — 다중 폭발
- **현재 코드**: `index.html:14095-14105`. 명중 시 `t.life = 0` 으로 즉시 소멸 = **1발 1폭발** 고정.
- **필요한 변경**: 폭발 카운터 + 재무장 타이머를 어뢰 객체에 **필드 추가**하고 `t.life = 0` 을 조건 분기로 교체.
- **난이도**: 중간
- **위험**: 재무장 중 무적 판정이 없으면 같은 적을 프레임마다 때린다. 개체별 쿨 필요.

### prismBolt (블랑슈) — 파편 굴절
- **현재 코드**: `index.html:16951-16960`. `s.hit = true` + `compactInPlace(ab.shards, s => s.life > 0 && !s.hit)` — 1회 명중 후 제거.
- **필요한 변경**: 굴절 카운터 + `hit` Set + 방향 재계산 로직 신설. `s.hit` 의 **의미 자체가 바뀐다**(제거 플래그 → 마지막 명중 대상).
- **난이도**: 중간
- **위험**: `compactInPlace` 술어를 함께 바꾸지 않으면 파편이 영원히 남는다.

### huntingClaw (카이라) — 참격파 반사
- **현재 코드**: `index.html:17127-17140`. `hit` Set 무제한 관통, 수명 만료로만 소멸. 아레나 경계 분기 없음.
- **필요한 변경**: 아레나 경계 반사 분기 + `hit` Set 초기화 + 수명 재충전.
- **난이도**: 중간
- **위험**: `hit` Set 초기화 없이 반사만 넣으면 같은 적을 다시 못 때리고, 초기화만 하고 쿨을 안 넣으면 경계에서 진동하며 무한 타격한다.

### moonShot (루나) — 탄환 귀환
- **현재 코드**: `index.html:14738-14830`. `if (b.pierces >= pierceMax) b.life = 0;` 즉시 소멸.
- **필요한 변경**: 귀환 상태 + `hit`/`pierces` 리셋 + 주기 카운터를 탄환에 **필드 추가**.
- **난이도**: 높음
- **위험**: ⚠️ 아레나 이탈 소멸(`S.despawnMargin`)이 귀환 경로에서 오작동하지 않게 예외 분기가 반드시 필요하다. 안 넣으면 귀환 탄이 경계에서 사라진다.

### petalStorm (사쿠라) — 중앙 복귀
- **현재 코드**: `index.html:16234-16260`. 편도 소멸(수명 만료). 중앙 복귀 없음.
- **필요한 변경**: 속도 반전 + `hit` Set 1회 초기화.
- **난이도**: 낮음
- **위험**: 없음. `stats`(petalLife/petalSpeed)는 이미 부착돼 있어 값 조정과 병행 가능.

### spritling (엘레미아) — 정령 재충전
- **현재 코드**: `index.html:8041-8090`. 접촉 시 `s.life = 0` — **접촉 = 자폭 소멸**.
- **필요한 변경**: 소멸을 **재충전 타이머로 교체**(정령 객체에 `recharge` 필드).
- **난이도**: 중간
- **위험**: `spawnCD` 재충원 병목의 의미가 통째로 바뀐다. 정령이 안 죽으면 `want` 채우기 로직이 항상 만족되어 `S.spawnCooldown`/`S.idleSpawnCooldown` 이 사실상 죽는다. 두 값의 재해석이 필요.

### inkBlot (스미카) — 먹점 다회 각인
- **현재 코드**: `index.html:19184-19215`. 접촉 시 `b.life = 0` — **1회 각인 후 소멸**.
- **필요한 변경**: 각인 횟수 카운터 + **적별 재각인 쿨**(`e._blotCD`) 신설.
- **난이도**: 중간
- **위험**: ⚠️ 쿨 없이 풀면 한 적이 한 먹점을 **프레임마다** 소모해 표식이 순식간에 만개한다. 쿨 필드가 필수.

## C. 표적·배치·정렬 규칙 — "누구를 / 어디를 때리는가" (8건)

### interceptorDrone (에이미) — 표적 중복 배제
- **현재 코드**: `index.html:16462-16485`. 드론별 독립 최근접 탐색, **중복 배제 없음** — 전 드론이 같은 적을 때릴 수 있다.
- **필요한 변경**: 프레임 단위 **예약 Set** 도입. 드론 루프가 서로의 선택을 알아야 하므로 루프 구조가 바뀐다.
- **난이도**: 중간
- **위험**: 적이 드론보다 적을 때 폴백(중복 허용)이 없으면 드론이 놀게 된다.

### solarFlare (솔라) — 잉여 채찍 재분배
- **현재 코드**: `index.html:17376-17381`. 최근접 우선 정렬 후 `Math.min(n, pool.length)` — 적보다 채찍이 많으면 **잉여분이 그냥 사라진다**.
- **필요한 변경**: 정렬 키를 maxHP 로 교체 + **잉여 채찍 재분배 루프 신설**(중첩 상한 4 / 50% 감쇠 등).
- **난이도**: 중간
- **위험**: 감쇠 없이 재분배하면 적 1체 상황에서 피해가 채찍 수만큼 곱해진다.

### refractionField (블랑슈) — 비복원추출
- **현재 코드**: `index.html:17077`. `pool[Math.floor(Math.random()*pool.length)]` 를 n회 — **복원추출**이라 같은 적이 중복 선택된다.
- **필요한 변경**: 선정 루프를 **비복원추출로 교체**.
- **난이도**: 낮음
- **위험**: 같은 능력의 관통 판정(§A)과 축이 다르다. 둘을 동시에 켜면 피해가 곱으로 뛴다.

### cardThrow (카르디스타) — 슈트 라운드로빈
- **현재 코드**: `index.html:7320-7385`. `const suit = (Math.random() * 3) | 0;` — 카드마다 독립 균등 추첨.
- **필요한 변경**: 추첨을 **능력 단위 라운드로빈 카운터로 교체**(`ab.suitTurn`).
- **난이도**: 낮음
- **위험**: `SUITS` 배열 길이 3 과 묶여 있어 값 하나로는 표현 불가. 배열이 바뀌면 함께 고쳐야 한다.

### phantomStage (트리나) — 환영 대상 동기화
- **현재 코드**: `index.html:18194-18240`. 실체와 환영이 **각각 독립적으로 무작위 적**을 고른다.
- **필요한 변경**: 예약 큐에 **대상 참조를 넣고**, 재생 시점에 대상이 죽었으면 무작위 폴백. 큐 스키마 변경.
- **난이도**: 중간
- **위험**: ⚠️ `_phantomDmg` 게이트(`try`/`finally`)는 **손대지 말 것**. 게이트를 끄면 "환영 n기 = 즉사 판정 n배" 가 되어 밸런스가 붕괴한다. `phantomTotalCap(0.90)` 도 킷 규약이라 옵션이 올려선 안 된다.

### understudyCall (트리나) — 환영 위치 기반 표적
- **현재 코드**: `index.html:19029-19050`. 대상이 순수 무작위 — **환영 궤도 좌표가 표적 선정에 전혀 관여하지 않는다**.
- **필요한 변경**: 환영별 **반경 내 최근접 탐색 루프 신설** + 사거리 밖이면 그 회차 쉬는 분기.
- **난이도**: 중간
- **위험**: 궤도 좌표가 처음으로 판정에 쓰인다. 사거리 밖 분기가 없으면 환영이 아레나 밖 적을 때린다.

### inkBlot (스미카) — 가중 배치
- **현재 코드**: `index.html:19209-19212`. `Math.random()` 각도 + `Math.sqrt(Math.random()) * ARENA_R * S.spawnAreaFactor` — 경로·적을 전혀 안 본다.
- **필요한 변경**: 밀집도/경로셀 탐색 후 **가중 배치로 교체**.
- **난이도**: 중간

## 참고 — stats 데이터화가 이미 끝난 범위 (v678)

값만 바꾸면 되는 옵션은 아래로 해결되었다. 단계 3 에서 **재작업 불필요.**

- 능력 **37종**에 `stats` 부착, 레벨 무관 상수 **204개** 이관
- 개입 지점: `state.abilityStatOverrides[<능력id>] = { <키>: <값> }` → `_S(ab)` 가 능력 정의의 `stats` 위에 병합
- ⚠️ `_S(ab)` 는 인스턴스당 **1회 지연 생성 후 캐시**한다. 런 도중 오버라이드를 갈아끼우려면 `ab._stats` 를 무효화하는 경로가 별도로 필요하다.
