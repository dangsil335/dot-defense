# 첫 플레이 튜토리얼 설계 (아크 제로)

작성일: 2026-07-22
현재 버전: v686 (SSR 등장 연출 v687 진행 중 — 튜토리얼 구현은 그 이후)

## 목표

첫 접속 유저가 솜니아(SSR)의 안내를 받으며 게임을 배우고, 튜토리얼 전용 행성에서 R5 진화 게이트까지 도달해 **솜니아로 강제 진화 → SSR 체험**을 하게 한다. 강제 완주(건너뛰기 없음). 한 번 완주하면 영영 재발 안 함.

## 핵심 결정 (확정)

| 항목 | 결정 |
|---|---|
| 진입 | 첫 접속(닉네임 생성 직후). **강제 완주** — 못 끝내면 정상 게임 진입 차단 |
| 플레이 | **진짜 게임 + 안내 오버레이**. 게임 루프를 조작하지 않고, 이벤트를 감지해 안내를 얹음 |
| 강제 방식 | **스포트라이트** — 전체 암전 + 대상만 구멍 뚫어 밝게 + 테두리 이펙트 + 그 외 클릭 차단 |
| 전용 행성 | 극단적으로 쉬움 · 게이팅(깨야 다른 행성 열림) · 솜니아 강제 진화 허용 |
| 보상 | `scoreReward` 등 대폭 삭감(파밍 방지) |
| 대사 | 솜니아 나른·반말·천진난만한 딸 톤 |
| 완료 | `META.tutorialDone` 영구 잠금 + 서버 동기화 포함. 재시청 없음 |

---

## 1. 상태 머신 (META.tutorial)

강제 완주라 재개 지점을 잘게 나눌 필요가 없다. 단계는 **거친 체크포인트**만:

```js
META.tutorial = {
  stage: 'intro' | 'planet' | 'evolved' | 'done',
  // intro   : 아직 인트로 대사/플레이 버튼 전 — 재접속 시 인트로부터
  // planet  : 튜토리얼 행성 플레이 중 — 재접속 시 행성 선택부터 다시(강제 완주라 진행 중 세이브 무시)
  // evolved : 솜니아 진화 완료, 게임 계속 중 — 재접속 시 이어하기 허용
  // done    : 튜토리얼 완주 — 이후 모든 잠금 해제, 정상 게임
};
```

- `stage` 가 `done` 이 아니면 **메뉴의 다른 모든 버튼(가챠·상점·도감·코어관리 등) 잠금** + 다른 행성 잠금. 오직 튜토리얼 경로만 클릭 가능.
- `done` 판정은 `tutorialDone` 불리언으로도 별도 저장(호환·명확성). 서버 동기화(`syncMetaToServer`)에 포함.
- **강제 완주라 "튜토리얼 행성 플레이 중 이탈" 은 진행 세이브를 버리고 행성 선택부터 재시작**한다(어중간 재개 없음). 단 `evolved` 이후(솜니아 진화 후)는 기존 이어하기로 복원 — 이미 SSR 체험을 했으므로.

## 2. 진입 흐름

```
스플래시(아크제로) → 로그인/닉네임 생성
  → [checkFirstLaunch 이후] META.tutorial 없으면 stage='intro' 로 튜토리얼 시작
  → 솜니아 인트로 컷인 (대사 3연, 나른·반말)
  → [스포트라이트] 플레이 버튼(startBtn)만 밝게 → 클릭 강제
  → [스포트라이트] 튜토리얼 행성만 밝게(다른 행성 잠금) → 선택 강제
  → 게임 진입 (stage='planet')
```

- `checkFirstLaunch`(약 23553)는 이미 스플래시 완료 신호 후 실행됨. 여기에 튜토리얼 분기를 얹는다.
- 인트로 컷인은 기존 `char-cutin` 시스템 재활용(일러 슬라이드 + 대사). 솜니아 일러 `icons/illust/somnia.png` 존재.

## 3. 인게임 안내 (이벤트 감지형)

게임 루프를 조작하지 않고, **자연 발생 이벤트를 감지**해 안내 말풍선을 얹는다. 각 안내는 **1회만**(META.tutorial 내 하위 플래그 or stage 진행).

| 트리거 | 감지 지점 | 안내 (솜니아 톤) |
|---|---|---|
| 게임 진입 직후 | 라운드1 시작 | "저것들이 너무 많아지면 우리가 밀려. 시간 안에 적당히 정리하면 돼 — 어렵지 않아." |
| 첫 레벨업 카드 | `levelUpChoices` 모달 표시 시 | "오, 카드 떴다! 이걸로 새 능력을 배우는 거야. 맘에 드는 거 골라 봐." |
| 첫 조합 카드 | 카드 목록에 조합 카드 존재 감지 | "잠깐, 이거! 완전 좋은 거야 — 두 능력이 합쳐지는 거라구. 무조건 이거!" (+ 스포트라이트로 조합 카드 강조) |
| R5 진화 게이트 | evoGate 표시 + 솜니아 카드 존재 | "이제 날 불러! 저 카드 누르면 내가 나와. 이번만 특별히 도와주는 거야." (+ 스포트라이트) |

- **패배 조건 안내**는 '패배조건' 단어 대신 위처럼 유도리 있게.
- 조합 카드 감지: 카드 생성부(약 27233 "조합 카드")에서 조합 옵션 유무를 본다. 실제 감지 방법은 구현 시 확정.

## 4. 스포트라이트 게이트

전체 암전 오버레이 + 대상 요소만 밝게 통과 + 테두리 이펙트 + 나머지 클릭 차단.

- **구멍 위치**: 대상 요소의 `getBoundingClientRect()` 로 런타임 계산(반응형·화면별 위치 대응). 고정 좌표 금지.
- **구멍 뚫기**: 대상 주변만 어둡게 하는 방식(예: 큰 `box-shadow` 스프레드로 화면을 덮되 대상 영역만 밝게, 또는 4분할 반투명 박스). 구현 시 기존 오버레이 패턴 확인 후 택일.
- **클릭 차단**: 오버레이 `pointer-events` 로 뒤 요소 차단, 대상만 통과.
- **강제 대상 3종**: ① 플레이 버튼(`startBtn`) ② 튜토리얼 행성(행성 선택 화면) ③ 진화 카드(솜니아행) + 조합 카드.
- 화면 전환(메뉴→행성선택→게임→진화게이트)마다 다음 스포트라이트로 넘어가는 훅 필요.

## 5. 튜토리얼 전용 행성

`PLANET_TIERS`(약 37273: terra/ignis/abyss)에 **4번째 튜토리얼 행성** 추가 또는 별도 처리. 난이도는 `state.asc` 객체로 조절.

- **극단적으로 쉬움**: `enemyHpMul` 최저 · `enemySpeedMul` 낮게 · `maxAliveAdd` 대폭 상향(잘 안 지게) · `roundTimeMul` 짧게(R5까지 빨리) · `eliteEscorts` 0.
- **보상 삭감**: `state.asc.scoreReward` 를 극소값(예: 0.05)으로. 게임 종료 시 처치 점수·최종 점수 모두 이 값이 곱해짐(약 22261·22300 확인). 추가로 `gearGoldGained`(남은 골드→강화재화)·`accountXpGained`도 튜토리얼이면 별도 배율로 삭감.
- **게이팅**: `stage !== 'done'` 이면 튜토리얼 행성만 선택 가능, 나머지 잠금. 기존 행성 잠금(`planet-lock`, 약 4226) 재활용.

## 6. 솜니아 강제 진화 (핵심·위험)

R5 진화 게이트에서 정상적으로는 SSR 합류에 가챠 해금이 필요(`_ssrOf`/`SR_TO_SSR`/`_evoTowerUnlocked`). 튜토리얼 한정으로 이를 우회.

- **우회**: 튜토리얼 행성(`stage==='planet'`)에서 R5 게이트가 뜰 때, 선택지에 **솜니아행 카드를 반드시 포함**하고 해금 게이트를 무시. 그 카드를 스포트라이트로 강제.
- **⚠️ 영구 오염 금지**: 강제 진화는 **런 `state` 한정**이어야 한다. `META`(영구)나 `gachaUnlocked` 에 솜니아 해금이 새면, 튜토리얼 후 정상 게임에서도 솜니아를 공짜로 쓰게 된다. 구현 시 진화 결과가 `state.character`(런 한정)에만 반영되는지 확인하고, `META` 오염 경로를 차단.
- 강제 진화 후 `stage='evolved'`. 이후는 정상 이어하기 허용.
- 솜니아 능력이 실제 발동하려면 진화 시 능력 셋업이 필요 — 기존 SSR 진화 경로가 능력을 어떻게 부여하는지 따라간다(별도 특수처리 최소화).

## 7. 완료 처리

- 진화 후 게임을 계속 플레이(솜니아 체험). **게임 종료(승/패 무관) 시 `stage='done'`, `tutorialDone=true`** 저장 + 서버 동기화.
- `done` 이 되면 모든 잠금 해제. 이후 튜토리얼 관련 코드는 전부 no-op.
- 재시청 없음. `done` 이면 `checkFirstLaunch` 의 튜토리얼 분기를 타지 않는다.

## 8. 재활용 재료 (신규 최소화)

- 대사·일러 컷인: `char-cutin`(6008), `showCharComboCutin`(34931), `_charPortraitImg`.
- 대사 테이블: `CHAR_AMBUSH_LINES`(34233)에 튜토리얼 전용 라인 추가 or 별도 `TUTORIAL_LINES`.
- 암전 오버레이: 기존 모달 backdrop / 이벤트 씬 패턴.

## 9. 위험 요약

| 위험 | 대응 |
|---|---|
| 강제 진화가 META 오염 → SSR 공짜 | 진화는 런 state 한정. META/gachaUnlocked 미기록 검증 |
| 튜토리얼 중 이탈로 상태 꼬임 | 강제 완주 + stage 체크포인트. planet 중 이탈은 행성선택부터 재시작 |
| 튜토리얼 행성 파밍 | scoreReward·gearGold·XP 삭감 |
| 튜토리얼 행성에서 패배 | 난이도 극단적 하향(maxAlive 대폭↑). 만약 져도 stage='planet' 유지 → 재도전 |
| 스포트라이트 좌표 어긋남 | getBoundingClientRect 런타임 계산 |
| 기존 "캐릭터 선택 폐지, standard 시작" 전제와 충돌 | 튜토리얼도 standard 로 시작하고 R5에서 솜니아 진화(전제 유지) |

## 10. 미결 (구현 중 확정)

- 조합 카드 감지의 정확한 방법(카드 생성부 데이터 구조).
- 스포트라이트 구멍 뚫기 CSS 기법(box-shadow vs 4분할 vs SVG mask) — 기존 패턴 확인 후.
- 튜토리얼 행성을 `PLANET_TIERS` 에 넣을지, 진입 시 임시 asc 주입으로 처리할지.
- 인게임 안내 말풍선 UI(솜니아 미니 초상 + 말풍선) 스타일.
