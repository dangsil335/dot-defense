# 장비 시스템 · 골드 역할전환 · 자동진행 — 설계서

> 작성일: 2026-07-13 · 대상: `index.html`(단일파일 ~33k줄) · 상태: 설계 확정, 구현 착수 전
> 목표: (1) 영구장비(메이플 잠재능력식) 메타-그라인드 추가로 장기 리텐션, (2) 골드를 인게임 소비에서 판-밖 장비재화로 전환해 인게임 UI 간소화, (3) 냥냥시노비식 완전 자동진행.

## 0. 원칙 & 레퍼런스

- 레퍼런스 게임: **냥냥 시노비(CookApps)** — 인게임 유저 액션은 카드(인술) 선택뿐, 나머지 재화·성장은 전부 판 밖(장식품/장비). 우리도 이 구조로 수렴.
- 우리가 이미 대등/우위: 조합(74) · 캐릭터 · 스토리 · 승천 · 주간/일일. **놓친 축 = 영구 장비 파밍 + 완전 자동.**
- 설계 철학: **골드 = 확정 성장(바닥) / 별조각 = RNG 추격(천장)**. 꽝은 "약함"이지 마이너스 아님.
- 버전 규율: 변경마다 `APP_VERSION`(index.html) + `CACHE='dot-defense-vNNN'`(sw.js) 동시 bump. 현재 v615.

## 1. 페이즈 분할 (안전한 순차 배포)

33k줄 단일파일. 한 번에 다 넣으면 깨진다. 각 페이즈는 **독립 배포·검증 가능**하며, 중간 상태가 항상 정상 동작.

| 페이즈 | 내용 | 코어 루프 침습 | 리스크 | 의존성 |
|---|---|---|---|---|
| **P1 자동진행** | 스마트 카드 자동선택 + 라운드 자동시작 토글 | ❌ 기존 타이머 확장 | 낮음 | 없음 |
| **P2 장비(별조각 리롤)** | 4슬롯·등급·잠재·드랍·리롤(꽝)·metaMods 주입·UI·동기화 | ❌ 순수 추가 | 중간 | 없음(별조각 기존) |

배포 순서 = P1 → P2 → P3. 각 페이즈 종료 시 버전 bump + 프리뷰 검증.

## 2. 페이즈 1 — 자동진행 (AUTO)

### 2.1 범위 (확정)
**완전 자동, 1판.** 토글 ON → 카드 스마트 자동선택 + 라운드 자동시작 + 게임오버까지 무개입. **오버 시 정지**(자동 재시작 없음 → 무한 파밍 악용 차단).

### 2.2 토글
- 상단 HUD 배속(▶▶) 옆에 `AUTO` 칩 추가.
- 상태 `state.autoPlay`(bool). 기본값은 `META` 선호도(`META.prefAutoPlay`)에서 복원 → 다음 판도 유지.

### 2.3 카드 자동선택
- 훅: `update()`의 자동선택 블록(현행 L23073~). 현재 `state.autoCardTimer` 실시간 deadline 방식은 그대로 재활용.
- 현행: "전부 보너스일 때만, bonusStardust 우선 else idx0". → **변경: `state.autoPlay`면 항상 발동, `scoreCard()` argmax 선택.**
- 딜레이: 카드 모달 표시 후 실시간 0.6s(뭘 골랐는지 보이게) 뒤 `applyLevelUpChoice(bestIdx)`.
- 카드 리롤(메타 업글 `reroll`)은 MVP에서 자동 사용 안 함(뜬 3장 중 최선만).

### 2.4 `scoreCard(c)` — 점수 (높을수록 우선)
카드 구조: `{action:'new'|'level'|'combo'|'ascendant'|'bonusScore'|'bonusStardust', id, tier, lucky, ...}`

| 우선 | 조건 | 점수 |
|---|---|---|
| 1 | `combo` tier3 (트리플) | 1000 |
| 2 | `combo` tier2 (일반 조합) | 900 |
| 3 | `new`/`level`이며 **트리플 경로 재료**(`COMBO_PARTNERS[id]`에 미완성 tier3 파트너, 파트너 보유/획득가능) | 800 |
| 4 | `new`/`level`이며 **일반 조합 경로 재료** | 700 |
| 5 | **범위 패시브**이고 내 빌드가 AoE 위주(보유 AoE 비율 ≥ 임계) | 650 |
| 6 | `level` 강화: superLucky 620 / lucky 600 / 일반 500 (조합관련 능력 +가점) | 500~620 |
| 7 | `new` (조합 경로 없음) | 400 |
| 8 | `ascendant` | 300 |
| 9 | `bonusStardust` 200 / `bonusScore` 100 | 100~200 |

- 동점 tie-break: 높은 tier/level → 랜덤.
- 재활용: `COMBO_PARTNERS[id]`, `findAvailableCombos()`, `getCardTier(c)`, `ABILITY_DEFS[id].isPassive`.
- **모드 적응**: 조합 존재 모드(클래식)는 1~4 우선, 디펜스(패시브+보너스만) 모드는 같은 함수가 5~9로 자동 작동.

### 2.5 AoE 태깅 (선행 데이터 작업)
- 현재 능력에 AoE 플래그 없음. `ABILITY_DEFS`의 광역기 항목에 **`aoe:true`** 수동 태깅 1회.
- "AoE 위주" = 보유 능력 중 `aoe:true` 비율이 임계(예 ≥40%) 이상 → 5번 규칙 발동.
- 태깅 없이는 5번(범위패시브 우선)이 불가하므로 P1의 필수 소작업.

### 2.6 라운드 자동시작
- 훅: `update()`의 `state.tdPrepPhase` 가드(현행 L23089). `autoPlay`면 prep 진입 후 실시간 ~0.8s 뒤 자동 Start.

### 2.7 검증
- 프리뷰에서 AUTO 토글 → 카드 모달 자동 소거 확인, 조합 카드 있을 때 조합 선택 확인, 라운드 자동 진행 확인, 게임오버 정지 확인.

## 3. 페이즈 2 — 장비 시스템 "전술 코어"

### 3.1 데이터 모델
```
META.gear = {
  equipped: { offense:gearId|null, targeting:.., supply:.., control:.. },
  inv: [ { id, slot, rarity, level, lines:[{key,tier,val}...], v } ],  // v=리롤 버전
  nextId: n
}
```
- 슬롯 4: `offense`(화력)·`targeting`(조준)·`supply`(보급)·`control`(제어). 슬롯별 고유 옵션풀.
- 등급(MVP 3): 커먼/레어/에픽 → (2차: 레전드/코스믹). 라인 수: 커먼1·레어2·에픽2·레전드3·코스믹3(+특수라인).
- `level`: 골드 강화 레벨(P3에서 활성. P2에선 0 고정 placeholder).

### 3.2 옵션 풀 (전부 기존 `metaMods` 필드에 매핑 → 전투코드 0수정)
- **화력**: `dmgBoost` / `comboPowerBonus` / 트리플위력 / 시작데미지
- **조준**: `bossDmgMul` / `executionerBonus`(저체력) / `onslaughtBonus`(고체력) / `pressBonus`(다굴) / `awakenBonus`(후반)
- **보급**: `goldMul` / `scoreMul` / `vampiricFlat` / `scholarMul`(강화-%) / 시작골드 / 스타더스트획득%
- **제어**: 쿨감 / `slowMul` / `luckyChanceBonus` / `roundTimeBonus` / `relicRarityBoost` / 슬롯+1(희귀)
- **코스믹 특수(2차)**: 슬롯+1 · 조합확정등장% · 매판 무료리롤 · "상위등급 라인 2개 랜덤"(프리즘)

### 3.3 획득(드랍) — 파밍처 = 플레이
- 게임 종료 시 확률 드랍(예 40%). 슬롯 랜덤. 등급은 도달 라운드/승천 가중(높이 갈수록 고등급↑).
- 라인은 드랍 시 등급 풀 내 랜덤 롤.
- 인벤 상한(예 60). 초과 시 분해 유도.
- 분해 → 별조각 소량(커먼1/레어3/에픽8/레전드20/코스믹50).

### 3.4 리롤(잠재능력 재설정) + 꽝 — 재화 = 별조각
싱크의 핵심. 3중 꽝 장치:
1. **라인 티어 롤**(굴릴 때마다): 하급55%/일반30%/상급12%/최상2.5%/프라임0.5%. 라인 2~3개 독립 → "전부 상급↑" 극악 → 반복 리롤 유발.
2. **빌드 미스매치**: 좋은 티어여도 내 빌드와 안 맞으면 실질 꽝(남에겐 보물).
3. **값 범위**: 같은 티어 안에서도 min~max 롤.
- UI: 리롤 → **새 라인 미리보기 → 적용/취소**(좋은 롤 실수 방지).
- 비용(별조각): 레어8/에픽15/레전드30/코스믹60 (등급 비례).
- 꽝 = 최소 0 이상. **마이너스 옵션 금지**(손도 안 대게 됨).
- 2차 QoL 싱크: 라인1개 고정 후 나머지만 리롤 / N회 리롤 시 상급1줄 소프트천장.

### 3.5 승급(합성, 선택)
같은 슬롯·같은 등급 3개 → 상위 1개(옵션 랜덤). 파밍 잉여 소모처. (2차)

### 3.6 통합 지점
- 효과 주입: 게임 시작 시 `state.metaMods` 생성 직후 `applyGearEffects(state.metaMods)` — 주간모디파이어 `_wm.apply()`와 동일 패턴. `damageEnemy` 배율체인이 그대로 소비.
- 획득: `endGame()` 보상집계 옆 드랍 롤 1블록.
- UI: 신규 `#gearScreen`(강화소·능력영구처럼 `.screen` 재사용) + 메뉴 나브 버튼. 리롤은 큐브식 before/after.

### 3.7 동기화 (SQL 0, merge 코드만)
- `inv`: id 기준 **유니온**(파밍 append-only라 안전).
- 리롤 변경: 코어별 `v`(버전) → **높은 v 채택**.
- `equipped`: 최근변경(metaUpdatedAt) 우선.
- 별조각 earned/spent 기존 방어 유지.
- ⚠️ 빼먹으면 기기전환 시 리롤/장착 롤백 버그(일일퀘 때와 동종).

### 3.8 밸런스/캡
- 슬롯당 옵션 기존 metaMods cap(5.0) 적용.
- 라인당 수치 modest, 총합 관리. 승천/초월 적HP 스케일로 흡수.
- ✅ **랭킹 공정성(해소)**: 우려 없음으로 결론. 리더보드는 이미 메타-투자 가중(강화소 scoreMul·8★·영구·승천) → 장비는 동일 성격의 추가지 새 불공정 아님. 다들 장착(상승하는 바다)이라 상대순위 보존, 별조각은 버는 재화(P2W 아님). 유일 고려 = 장비 점수영향 크기 → metaMods 캡(5.0)+modest 수치로 흡수(별도 정책 불필요).

## 4. 페이즈 3 — 골드 역할전환

### 4.1 인게임 골드 소비 제거
- 제거: `actEnhance`(강화, 현행 L22584) · 능력칩 up버튼 · `goldBonusScore`(골드→점수, 현행 L17708~) · (랜덤버튼은 TD모드 이미 숨김, 클래식은 별도 판단).
- 결과: 인게임 유저 액션 = **카드 선택뿐**. 우측 패널 = 순수 상태표시(도크).

### 4.2 골드 → 장비 레벨재화
- 게임 종료 시 `state.gold` → `META.gearGold`(가제)로 적립.
- 장비 화면에서 코어 **레벨업**에 소비(스타포스식, 레벨당 옵션 수치 %↑). = 골드 축(확정 성장).
- 별조각 = 리롤 축(RNG). 두 재화 성격 분리 완성.

### 4.3 파급 리워크 (골드 엮인 것들)
- 남은골드→점수 환산: **제거**(점수는 킬로만).
- 등가교환류 이벤트(골드 바쳐 버프): **무료 버프/다른 코스트로 리워크 or 제거**.
- 골드 스케일 유물(망자의 부적 등 획득골드 비례): 유지 가능(판당 획득 추적).
- 밸런스: 골드강화 제거로 능력레벨이 카드 RNG로만 → **카드 등장빈도/레벨업 곡선 상향 튜닝** 필요.

### 4.4 정체성 변화 (수용 전제)
액티브 로그라이크 → 방치형-라이트로 이동. 인게임 조작 재미(강화 판단) 감소, 메타 깊이(장비)로 대체. 함장 승인 완료.

## 5. 크로스커팅

- **버전 규율**: 페이즈 내 각 배포마다 APP_VERSION + sw.js CACHE 동시 bump.
- **폐쇄 경제 루프**: 플레이 → 코어 드랍 + (분해)별조각 → 별조각 리롤/골드 레벨업 → 강해짐 → 더 높이 → 더 좋은 드랍.
- **클로저 스코프 주의**: `META`/`CHARACTERS`/`ABILITY_DEFS` 등은 preview_eval에서 접근 불가 → UI 검증은 DOM 클릭으로.
- **저장 무결성**: META는 obfuscated/checksum → localStorage 직접 주입 불가, 게임 내 경로로만.

## 6. 미해결 결정 (착수 전 확정)

1. ~~랭킹 공정성~~ **해소됨**(§3.8): 리더보드가 이미 메타-투자 가중이라 장비도 동일 성격 → 결정 불필요. 밸런스(캡)로만 관리.
2. 수치표 최종값(드랍확률·리롤티어·옵션 min~max·골드 레벨비용): **그라인드 강도=하드코어 확정**(2026-07-13). 방향: 드랍 낮음(~25%)·고등급 드문 가중·리롤 하급60%+·리롤비용 높음(레어12/에픽25/레전드50 별조각)·분해환급 modest·BiS는 장기 추격. 정확값은 P2 구현계획에서.
3. AoE 임계(§2.5) 및 태깅 대상 능력 목록: P1 구현계획에서 확정.
